# Valtix

> Valtix is a multicloud network security platform (agentless, cloud-native firewall for ingress, egress, and east-west traffic across AWS, Azure, GCP, and OCI). Founded in 2018, Valtix was acquired by Cisco in 2023 and is sold today as Cisco Multicloud Defense; the Valtix documentation site and the verified Terraform provider remain live and maintained under the Valtix name.

Valtix publishes no public REST/OpenAPI reference. The supported programmatic
surface is the Valtix Terraform provider, which authenticates to the Valtix
Cloud Controller with a tenant API key file. The Controller forwards alerts to
customer webhook destinations (Slack, ServiceNow, PagerDuty, Microsoft
Sentinel, Webex) and forwards logs to SIEMs (e.g. Datadog).
